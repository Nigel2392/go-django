# SQLC Plugin (`go-django-definitions`)

> **OUTDATED / DEPRECATED**: The `cmd/go-django-definitions` SQLC plugin targets an earlier version of Go-Django and is no longer maintained. For Go-Django v2+, define models directly with [`attrs`](./attrs/attrs.md) and manage schemas and queries using the [`queries` ORM](../queries/docs/README.md) and [`migrator`](../queries/docs/migrations.md).

---

## Incompatibilities with Go-Django v2

Code generated by `go-django-definitions` does not compile against current Go-Django releases without manual fixes. Specifically, the generator templates produce:

1. **Outdated `Definer` signature**: Generates `FieldDefs() attrs.Definitions` instead of `FieldDefs(context.Context) attrs.Definitions`.
2. **Removed `attrs` types and helpers**: Emits `&attrs.FieldConfig{...}`, `attrs.Make(o, fields...)` (missing the leading `context.Context`), `attrs.Relate(...)`, and `FormWidget: func(attrs.FieldConfig)` instead of `&attrs.Config{...}` and `attrs.Make(ctx, o, fields...)`.
3. **Removed `models` interfaces**: References `models.Updater` and `models.Reloader`, which no longer exist in `src/models` (see [Models](./models.md)).
4. **Raw `*sql.DB` lookups**: Reads `*sql.DB` from `django.APPVAR_DATABASE` rather than `drivers.Database`.
5. **Legacy `contenttypes` and `admin` code**: Generates `ContentTypeDefinition` callbacks (`GetInstance`, `GetInstances`, `GetInstancesByIDs`) without `context.Context` arguments and targets older `admin.ModelOptions` fields.

Keep this document strictly as a legacy reference if maintaining an older codebase.

## Installation

```bash
go install github.com/Nigel2392/go-django/cmd/go-django-definitions@latest
```

## Legacy SQLC Configuration

The plugin reads options from a `sqlc.yaml` (`version: "2"`) codegen entry:

```yaml
version: "2"
plugins:
  - name: go-django-definitions-plugin
    process:
      cmd: "go-django-definitions"
sql:
  - schema: "./schema.sql"
    queries: "./queries.sql"
    engine: "mysql"
    codegen:
      - out: ./gen
        plugin: go-django-definitions-plugin
        options:
          package: "mypackage"             # Required: target Go package name
          out: "mydefinitions.go"         # Optional: defaults to "<package>.go"
          generate_admin_setup: true      # Optional: defaults to false
          generate_models_methods: true   # Optional: defaults to false
          emit_pointers_for_null: true    # Optional: defaults to false
          initialisms: ["id", "api", "url"]
          inflection_exclusions: []
          rename: {}
          overrides:
            - column: "mytable.myfilefield"
              go_type:
                import: "github.com/Nigel2392/go-django/src/core/filesystem/mediafiles"
                type: "SimpleStoredObject"
                pointer: true
```

## Legacy SQL Comment Directives

The generator parses SQL column and table `COMMENT` metadata using space-separated `key:value` pairs.

### Column Directives

- `fk:<table>` or `fk:<table>=github.com/user/pkg.Type`: Foreign key relation (`o2o:...`, `m2m:...`, and `fk_rev:...` are also parsed for one-to-one, many-to-many, and reverse foreign key relations).
- `label:"<text>"`: Custom human-readable field label.
- `helptext:"<text>"`: Custom help text for the field.
- `readonly:true`: Marks the field read-only and excludes it from generated `InsertableFields`.
- `form_<attr>:"<value>"`: Adds widget attributes under `WidgetAttrs`.

### Table Directives

- `readonly:col1,col2`: Marks multiple columns on the table as read-only.

### Legacy Schema Example

```sql
CREATE TABLE tickets (
    id         SERIAL PRIMARY KEY COMMENT 'readonly:true',
    title      VARCHAR(255) NOT NULL COMMENT 'label:"Title" helptext:"What is this ticket about?"',
    body       TEXT NOT NULL COMMENT 'label:"Body"',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'readonly:true'
);

CREATE TABLE notes (
    id         SERIAL PRIMARY KEY,
    body       TEXT NOT NULL,
    ticket_id  BIGINT UNSIGNED NOT NULL COMMENT 'fk:tickets',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (ticket_id) REFERENCES tickets(id)
) COMMENT 'readonly:id,created_at';
```
